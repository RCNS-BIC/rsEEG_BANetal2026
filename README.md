# rsEEG_repo
Repository containing the resting-state EEG pre-processing pipeline utilised in the manuscript 'Cognitive exertion reshapes resting-state EEG markers of ageing', available at: 

The pipeline is conducted in Automatic Analysis (version 5.8.1; ), runs on MATLAB (version 2024b, The Mathworks Inc., 2024) and utilises EEGLab (version 2024.2), and FieldTrip (git revision 2755b10) functionalities. For more details on each step, see the manuscript ().


For an overview of the utilised modules, see 'meeg_dvs_neuropsych.xml'. 
You can run the pre-processing via 'meeg_dvs_neuropsych.m'. 
'aap_prov.png' displays the pre-processing steps
